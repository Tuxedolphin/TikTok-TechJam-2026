The consequence

This is why your agents are still toys.

Nobody hands an agent real credentials and walks away. So agents stay in sandboxes, with fake keys and a human watching the terminal.

Permissions are all-or-nothing

An agent’s reach is whatever the platform handed it. So teams hand it nothing real.

Approving every step is doing the work

And an agent that floods you with prompts turns approval into a rubber stamp.

A flag after the fact is a receipt

Pattern-matching the command tells you what left. It does not stop it leaving.

The bottleneck is not model quality. It is that nobody can bound what a hijacked one reaches.

Why this is not already in the starter kit

The obvious design does not work.

Rejected — proxy on the host

The design most teams would ship: run the proxy on the host, point the container at it.

It cannot work. An internal network cuts off the host as well as the internet, so the container cannot reach that proxy at all. The policeman is on the wrong side of the wall.

Measured, not assumed.

Shipped — dual-attached sidecar

A container on the internal network can reach a sidecar by name, and can reach neither the host nor any public address.

Attaching that sidecar to a second network gives it a way out while every agent keeps none.

Verified on Docker / OrbStack.

The evidence it produces

Every decision is named.

AUTHZ-OWNER-010 Cross-user access — denied before grants are consulted, so no grant can ever authorize it.
AUTHZ-GRANT-011 Allowed by an active grant naming this host.
AUTHZ-REVOKED-013 The operator revoked it. Distinct from expiry, so the timeline shows intent.
NET-EGRESS-PRIVATE-024 A granted hostname resolved into link-local space — the cloud-metadata escape, closed.
HITL-EGRESS-FLOOD-027 Too many approvals held at once. An agent cannot turn the operator into a rubber stamp.

Known boundaries

We know exactly where the border stops.

TodayWhat closes it
Principals are fixtures — no authentication behind them. An identity provider. The enforcement path above it does not change.
HTTPS is authorized by hostname, not by path. TLS termination. Anthropic’s own sandbox documents the same limit — state of the art, not our shortcut.
Raw sockets and git+ssh are refused outright. A layer-4 gate on the same authorizer. Refusing is correct under default-deny meanwhile.
Quarantine strikes reset on restart; verified on Docker only. Persist strikes, and re-measure per container engine before claiming support.
